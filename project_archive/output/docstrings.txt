odbAccess.openOdb
============================================================
Doc: sys.modules['odbAccess'].openOdb(path) -> This method opens an existing output database (.odb) file and creates a new Odb object. You typically execute this method outside of Abaqus/CAE when, in most cases, only one output database is open at any time. For example,

import odbAccess
shockLoadOdb = odbAccess.openOdb(path='myOdb.odb')
